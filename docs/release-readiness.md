## Staging decision

**NO-GO for staging until identified technical blockers are resolved.** In particular:
retain local guards until target-specific connection/identity provisioning is reviewed;
resolve host filesystem/process/secret isolation; validate supported real ClamAV and
its complete-input/limit configuration before enabling confidential uploads. No
remote provisioner or deployment switch is supplied. A separate synthetic-data-only
staging scope may be proposed after those technical boundaries are reviewed; it is
not authorized by this report.

Live delivery, host restore/alert/supervision acceptance and all organizational/human
approval rows remain open. No existing service was changed and no real emails sent.
